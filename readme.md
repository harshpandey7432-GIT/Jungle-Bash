# 🌴 Jungle Dash — Endless Runner Game

**Jungle Dash** is a fun, browser-based endless runner game inspired by games like Temple Run. Run through a jungle, avoid obstacles, jump over logs, slide under gates, and collect golden coins!

## 🎮 Features

- 🌴 Jungle-themed environment
- 🏃 Three-lane endless running gameplay
- 🪙 Collectible golden coins
- 🪨 Obstacles such as rocks, logs, and gates
- 🦘 Jump and slide mechanics
- 📏 Distance tracking
- 📱 Mobile swipe controls
- ⌨️ Keyboard controls
- 🌐 Runs directly in a web browser
- 💻 Built using HTML, CSS, and JavaScript
- 🚫 No additional libraries or backend required

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Interface and styling
- **JavaScript** — Game logic, controls, collision detection, and animations
- **HTML Canvas** — Rendering the game environment and character

## 🚀 How to Run the Game

### Option 1: Run directly in a browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in your default browser.
5. Click **START GAME** and enjoy!

### Option 2: Run using Visual Studio Code

1. Open the `Jungle-Dash` folder in VS Code.
2. Open `index.html`.
3. Make sure the complete game code is saved.
4. Right-click the file and select **Open with Live Server**, if installed.

You can also open the HTML file directly in your browser without Live Server.

## 🎯 Game Controls

| Action | Keyboard Control |
|---|---|
| Move left | Left Arrow / A |
| Move right | Right Arrow / D |
| Jump | Up Arrow / Space |
| Slide | Down Arrow / S |

### Mobile Controls

Swipe left or right to change lanes.

Swipe up to jump and swipe down to slide.

## 🕹️ How to Play

1. Start the game.
2. Move between the three lanes.
3. Avoid rocks and other obstacles.
4. Jump over obstacles that can be cleared by jumping.
5. Slide beneath overhead gates.
6. Collect as many coins as possible.
7. Try to achieve a greater running distance!

Colliding with an obstacle without performing the correct action ends the run.
